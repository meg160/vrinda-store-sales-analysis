# vrinda-store-sales-analysis

##  Objective
To analyze sales data of Vrinda Store and identify key business insights related to customer behavior, sales trends, and performance.

##  Tools Used
- Microsoft Excel
- Pivot Tables
- Data Visualization

##  Dashboard Overview
This dashboard includes:
- Sales vs Orders trend
- Sales distribution (Men vs Women)
- Order status analysis
- Top 5 states by sales
- Sales channels
- Age group analysis

## Key Insights
- Women contribute ~98% of total sales
- 93% of orders are successfully delivered
- Amazon and Myntra are top-performing channels
- Maharashtra is the highest revenue-generating state
- Adult age group contributes the most sales
